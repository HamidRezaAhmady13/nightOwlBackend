 1. Call Stack (Sync code)
   ↓
2. process.nextTick queue (Node's highest priority microtask)
   ↓
3. Promise Microtask queue (.then, .catch, queueMicrotask)
   ↓
4. Event Loop Phases (Macrotasks):
   → Timers
   → Pending Callbacks (System errors)
   → Poll (I/O)
   → Check (setImmediate)
   → Close


EVENT LOOP (the whole mechanism)
  ├── runs Sync code (call stack) until empty
  ├── drains nextTick queue
  ├── drains microtask queue
  ├── runs Phase 1: Timers        ← processes macrotasks here
  ├── drains nextTick + microtasks
  ├── runs Phase 2: Pending       ← macrotasks
  ├── drains nextTick + microtasks
  ├── runs Phase 4: Poll          ← macrotasks (I/O)
  ├── drains nextTick + microtasks
  ├── runs Phase 5: Check         ← macrotasks (setImmediate)
  ├── drains nextTick + microtasks
  ├── runs Phase 6: Close         ← macrotasks
  └── repeats forever
